# JobBoard

A job portal web application that connects candidates with job opportunities.

## Features

- Browse available jobs
- Search jobs by title and location
- Enter candidate credentials
- Find matching job opportunities
- Candidate and employer features

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run

1. Install dependencies:

npm install

2. Start the server:

node server.js

3. Open the application in the browser.
